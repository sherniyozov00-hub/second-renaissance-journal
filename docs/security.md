## Ma’lum cheklovlar

- CSP skriptlarni cheklamaydi, chunki Next.js o‘z bootstrap skriptini inline joylashtiradi. To‘liq
  nonce asosidagi CSP har sahifani dinamik qiladi; XSS’ga qarshi asosiy himoya — HTML sanitizatsiyasi.
- Rate limitlar xotirada saqlanadi, shuning uchun ilova bitta nusxada ishlashi kerak. Gorizontal
  kengaytirishda ularni Redis’ga ko‘chirish kerak.
- Shaxsiy ma’lumotlarni qayerda saqlash bo‘yicha yakuniy qarorni yurist qabul qiladi (TZ 17). Deploy
  istalgan mahalliy serverga qo‘yiladigan qilib yozilgan.
